# Мапа тривог — симулятор (без ключів)
Відкрий `index.html` (потрібен інтернет для карти). Для GitHub Pages: завантаж папку в репозиторій → Settings → Pages.
Якщо OSM-шар порожній при відкритті з диска — запусти `python -m http.server` у цій папці.
У `config.js` можна вказати `HOSTS` — тоді копії на інших доменах не запустяться. Ліцензія — див. LICENSE.
Дані: OpenStreetMap, Esri, geoBoundaries, EugeneBorshch/ukraine_geojson.

## Що нового
- Іконки цілей беруться з `drones/*.svg` (для «Ракети» і «Бандероль» використано `ic_banderol.svg`, окремої іконки ракети в папці немає).
- Теми «🌙 Темна» і «🗺 Світла» малюються з `drones/black_ukraine_map.svg` та `white_ukraine_map.svg`. Для цього сайт має відкриватися через сервер (`python -m http.server`, GitHub Pages), а не з диска.
- Лого — `img/favicon.ico`; праворуч угорі — лічильник «Загрози» (клік — розбивка за типами).
- Адмін → «🚨 АС Тривог»: автоматична тривога в районах за радіусом цілі (налаштовується там же).
- Маршрут об'єкта задається кліками по карті (кілька точок, зиґзаґ), а не азимутом.
- Тривогу можна вмикати по районах або по цілих областях (перемикач у панелі, є пошук).
- Клік по області/району показує історію подій (час, тип тривоги, хто вмикав: вручну чи АС Тривог, рух цілей). Зберігається в браузері.
- ТГК-стрічка (вигадані канали) у кутовій панелі; тексти пише Groq, якщо вказано `GROQ_KEY` у `config.js`, інакше — за шаблоном.
- Райони: лише 136 основних (як на офіційній мапі тривог). Якщо джерело містить дрібніші райони, вони автоматично об'єднуються (потрібен Turf.js з CDN).
- Оптимізація: менше об'єктів на мапі, базові SVG-теми й маска малюються на canvas, відкладене збереження/оновлення панелей, легша анімація тривог. Іконки цілей мають малий фіксований розмір (22 px) незалежно від масштабу.
- Ще оптимізація: усі вектори малюються на canvas (плавніше при масових тривогах, мигання тривог прибрано), райони кешуються в браузері (швидший повторний запуск), анімація ставиться на паузу у фоновій вкладці.

## Версія 3
- 💥 Кінець маршруту = вибух (анімація хвиль, зона удару, звук за ввімкненої сирени). Про нього пишуть 2–3 різні канали ТГК з різним стилем; ШІ отримує «персону» каналу, випадкове побажання до форми й список останніх повідомлень, щоб не повторюватись. Без ключа — запасні шаблони (12 каналів × 4 стилі × варіанти), місце удару береться з району.
- 🇺🇦 «Лише Україна»: контур будується з меж областей (кеш у браузері), решта світу закрита, карта не виїжджає за межі країни; вимкнено — вільна карта світу.
- Підказка з назвою району при наведенні прибрана — меню лише по кліку.
- Нижня панель швидкого запуску: тип → торкнутися старту → торкнутися кінця (повторюється, ×1/3/5/10, 〰 — складний маршрут).
- Клік по «Загрози» відкриває меню: район, рівень, час початку, тривалість; клік по рядку підсвічує загрози району та їхній пройдений шлях.
- Оптимізація: менше оновлень DOM, легші тайли/канвас і інтервали на телефонах, без blur, швидший збір маски.
